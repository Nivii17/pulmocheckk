# PulmoCheck: Respiratory Risk Prediction

A small web app that predicts a patient's respiratory risk level (Low, Medium or High). Enter a patient ID and it shows the predicted risk with a confidence score, the patient's history, current symptoms, test readings, and the main risk factors.

## Features
- Patient lookup by ID (P1 to P1000) using a SQL query on a SQLite database
- Random Forest classifier with a preprocessing pipeline and 5-fold cross-validation
- Risk level with confidence percentage
- Patient history (smoking, alcohol, family history, past lung condition, pollution and occupational exposure, allergies), current symptoms and test readings (oxygen saturation, lung function)
- Main risk factors summary

## How it works
1. `train.py` loads the patient data, checks for missing and duplicate rows, stores all patients in a SQLite table (`pulmo.db`), preprocesses the data, trains a Random Forest, evaluates it, and saves the model (`model.pkl`).
2. `app.py` is a Flask web app. It fetches the patient with a SQL `SELECT`, feeds the record to the model, and shows the prediction with history, symptoms and risk factors.

## Data preprocessing
- Checked for missing values and duplicate rows (none found).
- Kept `Patient Id` only as a lookup key, never as a model input.
- Text columns (smoking status, wheezing, past lung condition and so on) are converted to 0/1 columns with one-hot encoding inside a scikit-learn pipeline, so the app can feed raw patient records straight to the model.
- Stratified 80/20 train/test split, so every risk level appears in both parts.

## Dataset
`respiratory_patients.csv` (also as `respiratory_patients.xlsx`): **1,000 synthetic patients** with 17 features and a `Risk Level` label (Low, Medium, High). The data was generated by a script with a fixed random seed. The patients are not real. The risk label is built from the other columns plus random noise.

## Tech
Python, Flask, scikit-learn, Pandas, SQLite

## Run it
```
pip install flask pandas scikit-learn
python train.py
python app.py
```
Open `http://127.0.0.1:5000/` and enter a patient ID such as `P1`, `P37` or `P500`.

## Results
On the synthetic data: about 79% 5-fold cross-validated accuracy on the training split and about 81% on the 200-patient hold-out test set, with a per-class precision and recall report printed by `train.py`.

## Limitations
- The data is synthetic, so these numbers show that the pipeline works, not how it would perform on real patients.
- The "main risk factors" list uses simple threshold rules (for example oxygen below 94%); it is not an explanation produced by the model.
- This is a learning project and is not for medical use.
